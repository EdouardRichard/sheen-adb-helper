## 三模拟器跨实例闭环

- Android 16 主控、Android 12 动态无线调试目标和 Android 9 旧版目标均使用显式模拟器串号，组网步骤见项目根目录的 AI Agent 复现提示词。
- 发现列表只呈现调试服务，不呈现配对服务端口；未知动态调试目标进入共享配对浮层，配对码成功后自动解析并连接调试服务。
- Android 9 的 5555 目标显示“直接连接”确认且不进入配对浮层；连接后应用、进程、文件、终端等连续 8 次快速切页保持同一 Session。
- Android 12 完成文件上传、覆盖冲突与 SAF 下载；下载在单一 Sync 子流中完成传输前校验、接收和传输后校验，输出非空且返回页面后 Session 保持。
- 应用安装、强制覆盖、提取、停止、禁用、启用和卸载均完成；进程 CPU/内存、Shell 实际执行、按需 Logcat、远端断链自动返回未连接态均完成。

## 本轮发现并修复

- 所有功能页统一复用连接页顶部栏。
- 文件成功、APK 安装成功不再复用错误的终态文案。
- 文件传输取消可协作终止，不再为清理任务强制断开 Session。
- 系统应用解析兼容特殊框架包名和单个命名 APK；应用名称元数据开始实际消费。
- SAF 选择器进入后台时保留待完成任务。
- 可靠元数据文件下载复用单个 Sync 子流，避免连续开关子流触发远端关闭；低能力设备继续使用摘要完整性回退。
- 进程 CPU 计数器修正 shell 位置参数；PSS 不可读时回退 RSS；确认期间暂停轮询并显示终止结果。
- Shell 辅助键不再由 Esc 独占整行。
